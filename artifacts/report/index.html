Methodology

RuleCheck
V1Contract JSON is valid against the schema
V2Each quote appears verbatim on its cited page; names appear in their quotes; enum values appear in their citations; samples are verbatim
V2bRequired flag and type match the single-line table row
V3The document's own samples parse as JSON and validate against the extracted contract
V4Method and path match the deterministic segmenter's hints
V5Every table row the detector finds is present in the contract

A sample conflict becomes a finding about the document only when both sides are grounded in the document. Otherwise the section is retried (at most 3 attempts) or quarantined.

Limitations

  • Validated on one vendor PDF with a regular table layout. Other layouts may need new row detectors.
  • Prose-only rules (conditional requirements, version notes) are captured as descriptions, not verified semantics.
  • Client conformance covers Python Pydantic models only.
  • Hand-audit precision has the confidence interval of the audited sample size; the interval is shown next to the value.
  • Rows whose cells wrap across lines cannot be row-checked; they are reported as not checked, never as passed.
