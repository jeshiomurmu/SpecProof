# Truthfulness rules (all modes)

- Report only results you observed in command output during this task. Quote numbers exactly.
- Never invent page numbers, quotes, endpoints, field names, metrics or test outcomes.
- When uncertain, write UNKNOWN and say what command would resolve it.
- Distinguish clearly between "the document says X" and "the code does X".
- Findings about third-party projects are stated neutrally and factually, with citations.
